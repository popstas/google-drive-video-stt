## 3. Находки

### 🔴 Баги
1. **Dockerfile не копирует `config/`.** При дефолте `DEEPGRAM_KEYTERMS_ENABLED=true` + `DEEPGRAM_KEYTERMS_FILE=config/deepgram-keyterms.txt` `load_config()` падает `ValueError` (`config.py:125`) → стоковый контейнер `python -m src.main` крашится на первой расшифровке. Фикс: `COPY config ./config`.
2. **`relabel_transcript`:** заявление «дословно/byte-for-byte» неверно (текст `.strip()`+склейка через пробел, `:71,80,87,125`); KRISP-строки `^\d+$` или `^#{1,6}\s` **молча выбрасываются** (`:76-78`, потеря данных); `mmss` лоссово схлопывает часы (`[01:30:00]`→`90:00`, `:51-57`).
3. **`output._write_to_folder` игнорирует `existing_id`** (`:50-60`) — идемпотентность в `folder` иная, чем в `drive`; при переименовании исходника старый файл осиротеет, хотя docstring обещает «overwrite in place».
4. **`drive.list_folder_state`** — fallback по stem ложно сматчит пользовательский `notes.keypoints.md` как артефакт `notes.mp4` (`:139-141`).
5. **`postprocess` canonical-ветка** (`:192-199`) может насильно взять `Speaker 1..expected` как реальных, даже если доминирующий спикер пронумерован вне диапазона → главный говорящий приклеится к чужому имени.
6. **Операционный потолок:** без чанкинга файл длиннее лимита sync `/v1/listen` Deepgram жёстко падает (504→STTError) без фолбэка — задокументировать.

### 🟡 Лишнее / мёртвый код
- `drive.rename_file` — вызывается только из теста.
- `Config.telegram_bot_token` / `telegram_chat_id` — нигде в `src/` не читаются (`notify.py` берёт `os.environ` напрямую).
- `ARTIFACT_TYPE_PROPERTY` — пишется (3×), нигде не читается.
- `Config.deepgram_keyterms_enabled` / `deepgram_keyterms_file` — наружу не читаются, только внутри `config.py`.

### 🟠 Над-абстракция (наследие мультипровайдера)
- `STTProvider(ABC)` + `get_provider()` + `UnknownProviderError` — фабрика с одной веткой; можно схлопнуть в прямой `DeepgramProvider(...)`.
- `transcribe._log_deepgram_cost(provider: object, …)` — `getattr`-утиная типизация и двойной guard на `cost_usd`.
- `deepgram_usage.py` (81 строк) — хрупкий best-effort зонд цены (`projects[0]`, racy `?limit=100`), влияет только на лог-строку. Кандидат на упрощение/удаление вместе с плумбингом `cost_usd`.

### 🟢 Чисто
Leftover-hunt пустой; зависимости все используются; доки/env/CLI консистентны (проверяется тестом); `auth.py` и `extractor.py` (`encoding`/`errors`) — аккуратные правки; парные удаления провайдеров чистые.
